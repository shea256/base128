# Base128 JavaScript / TypeScript

```ts
import {
  encode, decode, encodeInteger, decodeInteger, createAlphabet,
  BinaryEncoder, BinaryDecoder, DEFAULT_ALPHABET_TEXT,
} from 'base128-unicode-codec';

const encoded = encode(new TextEncoder().encode('Hello 世界'));
const decoded = new TextDecoder('utf-8', {fatal: true}).decode(decode(encoded));

const integerText = encodeInteger(1000n); // '7β'
const number = decodeInteger(integerText); // 1000n
// Optional: precompile a custom alphabet for repeated calls.
const alphabet = createAlphabet(Array.from(DEFAULT_ALPHABET_TEXT).reverse().join(''));
console.log(encode(new TextEncoder().encode('Hello'), {alphabet}));
```

Zero runtime dependencies. TypeScript declaration files are generated by `tsc` and included in `dist/`.
See [`../../specs/encoding.md`](../../specs/encoding.md) for the wire format.

The npm package name `base128-unicode-codec` is proposed, **not verified available**.

The `TWO_BYTE_ALPHABET` / `TWO_BYTE_ALPHABET_TEXT` exports provide the optional
fixed two-byte preset. Pass `{alphabet: TWO_BYTE_ALPHABET}` to encode or decode.
Decoders (`decode`, `decodeInteger`, `BinaryDecoder`) additionally accept
`{acceptAliases: true}` to accept default and two-byte symbols, even mixed.
Strict decoding remains the default; alias mode rejects unrelated custom layouts.
See the root README for the six alias pairs and examples.
