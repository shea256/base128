01 / ENCODE · DECODE

Playground

Convert text, hexadecimal bytes, or unsigned integers into Base128.

Runs locally in your browser
Text is encoded to UTF-8 bytes first
Base128 payload
Custom alphabet optional · 128 unique Unicode code points

Default: format v4 (digits first). For v1, v2, or v3 payloads, supply the original alphabet. Both encoders and decoders must use exactly the same alphabet in the same order. No prefix or alphabet identifier is embedded in the payload.

02 / SIZE ANALYSIS

Encoding comparison

Displayed characters and UTF-8 storage size are not the same thing.

Input size—bytes
Base128 characters—Unicode code points
Base128 UTF-8 size—bytes
Base64 characters—unpadded
Base128 uses fewer displayed characters than Base64, but Unicode characters can occupy multiple UTF-8 bytes. Storage-size advantage is not guaranteed.

05 / DEVELOPERS

Using Base128

Encode bytes or integers with either library. Both use the same alphabet and produce identical output. These examples use a repository checkout; see the README for setup.

JavaScript

import { encode, decode, encodeInteger } from './packages/js/dist/index.js';

const bytes = new TextEncoder().encode('Hello!');
const encoded = encode(bytes);
const recovered = decode(encoded);

const number = encodeInteger(1000n); // "7β"

Python

from base128 import encode, decode, encode_integer

raw_bytes = "Hello!".encode("utf-8")
encoded = encode(raw_bytes)
recovered = decode(encoded)

number = encode_integer(1000)  # "7β"
